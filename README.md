# VACA: Visual Assembly Code Analyzer

A web app that parses and runs 8086 assembly step by step, and animates what happens inside the CPU.

**Live demo:** https://equipo-alfa-super-mega-dinamita.github.io/VACA-Project/

> **About the course:** an undergraduate course in the Systems and Computing Engineering program on how programming languages are defined and implemented: grammars, parsing, interpretation and language paradigms. The final project asked each team to build a language tool on top of a parser generator.

## Features

- **Grammar:** an ANTLR grammar for a subset of 8086 assembly ([`grammar/asm8086.g4`](grammar/asm8086.g4))
- **Interpreter:** a visitor builds the program, then an executor runs it over registers and RAM
- **Visualization:** p5.js animation of the registers, instruction queue, execution unit and memory
- **Editor:** in-browser editor with syntax highlighting, plus examples ([factorial](examples/factorial.86), [fibonacci](examples/fibonacci.86), [division](examples/division.86))

<details>
<summary><b>Running it</b></summary>

```sh
yarn install
yarn start   # dev server on http://localhost:3000
yarn deploy  # build and publish to GitHub Pages
```

The project uses `react-scripts` 3.2 (2019). On Node 17+, set `NODE_OPTIONS=--openssl-legacy-provider`, or upgrade `react-scripts`.

</details>

<details>
<summary><b>Known issues</b></summary>

- **Partial instruction set:** `MOV ADD SUB MUL DIV INC DEC PUSH POP LOOP HLT`. Flags and conditional jumps are not implemented (the last commit is "Basic Operations without flags").
- **Duplicated assets:** `P5_Tests/` duplicates the assets and a full copy of p5.js.
- **Licensing:** some bundled fonts are trial/demo versions, and the media clips are copyrighted. Check their licenses before redistributing.
- **Outdated dependencies:** pinned to 2019–2020 versions, with open Dependabot alerts.

</details>
